# Java OOP Banking Application

## Project Description

This is a console-based banking application developed using Java. It allows users to create bank accounts, deposit money, withdraw money, and check account balances.

## Features

* Create Savings and Current Accounts
* Deposit Money
* Withdraw Money
* Check Account Balance
* View Account Details
* View All Accounts

## OOP Concepts Used

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

## Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Scanner

## How to Run

Compile the Java files:

```bash
javac *.java
```

Run the application:

```bash
java Main
```
